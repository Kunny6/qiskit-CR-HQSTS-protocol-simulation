**qiskit-CR-HQSTS-protocol-simulation**
Source code for reproducing numerical simulations in the paper. Implementation based on Qiskit, five-qubit cluster state protocol (as designed in the manuscript).
**Code for Reproducing Paper Results**
This repository contains the Qiskit simulation code to verify the results presented in our manuscript.
> Note: This implementation corresponds to the protocol **without coercion-resistance function**, consistent with the design described in the paper.

**Environment**
python >=3.9
qiskit
qiskit-aer
matplotlib
Install dependencies:
```bash
pip install qiskit qiskit-aer matplotlib
````
**Run**
python main.py

**Reproducibility**
All parameters and circuit construction strictly follow the setup in the paper. Readers can directly run the script to verify the findings.
